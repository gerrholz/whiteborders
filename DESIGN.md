# Whiteborders product design

## Product

Whiteborders is an iPhone photo-framing app for preparing clean square images. The first workflow is deliberately narrow:

1. Select a photo from the device.
2. Preserve the complete source image without cropping or stretching it.
3. Center it horizontally and vertically in a square output canvas.
4. Add a uniform white border, initially 7% on every side.
5. Optionally show selected camera details as visible pixels.
6. Save a new image without copying embedded source metadata.

All photo bytes and metadata stay on the device. The app has no accounts, cloud processing, analytics, advertising, or direct social-network publishing.

## Initial interface

The editor contains a square preview, a compact photo strip, border size and color controls, a camera-details toggle, and a save action. The visual language is warm, restrained, and photography-led. Controls must work with Dynamic Type, VoiceOver, and touch targets suitable for one-handed use.

## Deferred

Cropping, zooming, manual positioning, multi-photo documents, batch export, presets, alternate ratios, advanced border effects, and direct publishing are not part of the initial workflow. They should be added only after a concrete user need is established.
