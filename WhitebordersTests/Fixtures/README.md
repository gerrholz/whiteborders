# Native test fixtures

These tiny JPEG and PNG files are generated geometric color grids. They contain no personal photographs or copied metadata and are dedicated to the public domain under CC0-1.0.

The inspectable PPM files in `Sources/` contain every source pixel. The files were converted with macOS image tools, and identifying metadata was removed. `catalog.json` records expected dimensions and formats. Test resources remain in the XCTest bundle and are not copied into the application bundle.
